# دليل بناء نسخة ويندوز المكتبية (.exe + Setup)

## المتطلبات على جهاز البناء
- Windows 10 أو 11 (64-bit)
- Node.js 18 أو أحدث: https://nodejs.org
- (اختياري — لبناء Setup) Inno Setup 6: https://jrsoftware.org/isdl.php

## الخطوة 1: بناء التطبيق الخام (.exe portable)

افتح PowerShell داخل مجلد المشروع ثم:

```powershell
npm install
npm run build:windows
```

سيتم إنتاج:

```
release\OPVM-win32-x64\
    OPVM.exe        ← التطبيق الجاهز (بدون تنصيب)
    resources\
    ...
```

يمكنك تشغيل `OPVM.exe` مباشرة، أو نسخ المجلد كاملاً لأي حاسوب ويندوز.

## الخطوة 2 (موصى بها): بناء مثبّت Setup.exe

بعد تثبيت **Inno Setup 6** والتأكد من إضافة مساره إلى `PATH`
(أو استخدام الأمر الكامل `"C:\Program Files (x86)\Inno Setup 6\ISCC.exe"`):

```powershell
npm run build:installer
```

سينتج ملف واحد جاهز للتوزيع:

```
release\OPVM-Setup-1.0.0.exe
```

هذا الملف:
- مثبّت رسمي بواجهة عربية/فرنسية/إنجليزية.
- يضع التطبيق في `Program Files\OPVM`.
- ينشئ اختصاراً في قائمة Start وعلى سطح المكتب.
- يضيف "إلغاء التثبيت" في لوحة التحكم.
- يستخدم أيقونة OPVM الذهبية وشاشة الترحيب.

## شاشة الترحيب
عند تشغيل التطبيق تظهر شاشة splash بخلفية ديوان وادي ميزاب لمدة ~1.2 ثانية،
ثم تُغلق تلقائياً وتُفتح النافذة الرئيسية بحجم كامل.

## كلمة المرور الافتراضية
- البريد: `admin@opvm.local`
- كلمة المرور: `admin123`

(يمكن تغييرها لاحقاً من صفحة المستخدمين)

## مكان حفظ قاعدة البيانات
```
%APPDATA%\OPVM\opvm-db\
```

## النسخ الاحتياطي
استخدم صفحة "النسخ الاحتياطي" داخل التطبيق لتصدير ملف JSON
ونقله بين الأجهزة أو بينه وبين النسخة السحابية.

## الميزات التي تعمل بدون إنترنت
- الأرشيف الكامل وإدارة الملفات
- الاجتماعات والاستدعاءات
- الأرشيف القانوني
- سلة المحذوفات
- النسخ الاحتياطي/الاستيراد JSON

## الميزات التي تحتاج إنترنت
- البحث الحكومي (gov-search)
- استخراج النصوص بالذكاء الاصطناعي (OCR)
- مساعد الذكاء الاصطناعي

## ملفات الأصول (Icons / Splash)
- `build/icon.ico` — أيقونة Windows متعددة المقاسات (16→256).
- `build/icon.png` — أيقونة المصدر.
- `build/splash.png` — صورة شاشة الترحيب.
- `build/splash.bmp` + `build/icon-small.bmp` — صور معالج Inno Setup.
- `build/installer.iss` — سكربت Inno Setup.

لتعديل الأيقونة، استبدل `build/icon.png` ثم نفّذ:
```powershell
magick build\icon.png -define icon:auto-resize=256,128,64,48,32,16 build\icon.ico
```
